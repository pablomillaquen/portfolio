## Resumen

Portfolio personal desarrollado con Laravel 12 + Vue 3, con soporte bilingüe (español/inglés), panel administrativo CRUD, galería de proyectos, blog, cursos, certificaciones y formulario de contacto. Diseñado como SPA con tema claro/oscuro.

## Descripción

Este proyecto es un sitio web portafolio personal creado por Pablo Millaquen para mostrar su trabajo como desarrollador. Está construido con una arquitectura moderna que combina Laravel 12 como API REST en el backend y Vue 3 (Composition API) como SPA en el frontend. Incluye un panel administrativo completo con CRUD para gestionar proyectos, posts de blog, cursos, redes sociales y la configuración del sitio. Cuenta con soporte completo para alternancia entre español e inglés, así como un selector de tema claro y oscuro. El frontend utiliza Tailwind CSS v4 para el diseño visual y Vite 7 como bundler, mientras que el backend usa PHP 8.3 y MySQL como base de datos.

## Summary

Personal portfolio built with Laravel 12 + Vue 3, featuring bilingual support (Spanish/English), admin CRUD panel, project gallery, blog, courses, certifications, and a contact form. Designed as an SPA with light/dark theme support.

## Description

This project is a personal portfolio website created by Pablo Millaquen to showcase his work as a developer. It is built with a modern architecture combining Laravel 12 as a REST API backend and Vue 3 (Composition API) as an SPA frontend. It includes a full admin panel with CRUD functionality to manage projects, blog posts, courses, social media links, and site configuration. It features complete language switching between Spanish and English, as well as a light/dark theme selector. The frontend uses Tailwind CSS v4 for styling and Vite 7 as the bundler, while the backend runs on PHP 8.3 with MySQL as the database.
